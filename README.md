# inFAMOUS 2 iOS website

Standalone technical overview hosted at https://monsdevo.github.io/infamous2-ios/.
Extracted from Monsdevo/monsgames; the portfolio remains at https://monsgames.net/.

Run `npm run build` to regenerate `infamous2-ios/index.html` and create the production files in
`dist/client`. Run `npm test` to verify the generated page and its local assets.
Run `npm run dev` for a local preview at http://127.0.0.1:4174/infamous2-ios/.

GitHub Pages should publish the `main` branch from `/` (root).
See [the maintenance guide](scripts/INFAMOUS2.md) for content and gallery updates.

The root URL intentionally has no index page and returns GitHub Pages 404.
